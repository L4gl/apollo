# ![Logo](chrome/app/theme/chromium/product_logo_64.png) Apollo

Apollo is an open-source fork of Chromium.

## Pros and Cons

Now it's time to talk about what Apollo has, that Chromium doesn't!

### Pros

1. Adblocking
2. Cookie Editor
3. I try and fix issues that are in Chromium
4. You get to say you use Apollo
5. A nice community

## Security

I always have been a person that loved security. I have no affiliation with Chromium, so please try and read up on their security stuff. I personally collect NO data, but I can't say the same for Chromium. Anyways, I implemented uBlock Origin for Adblocking, Privacy, and it's generally an amazing extension for that stuff.
